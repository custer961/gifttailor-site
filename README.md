# GiftTailor

A bespoke gift atelier — custom songs written by hand, delivered within 96 hours.

**Live site:** https://gifttailor.com

---

## About this repository

This repository hosts the **production build** of the GiftTailor storefront so it
can be served as a static site. It contains only the published assets —
HTML, CSS, JavaScript and media — exactly as served on gifttailor.com.

It is **not** the development source tree. No build tooling, no component
sources, no configuration.

## What the site includes

- Landing page with bilingual (EN / 中文) copy and language switching
- Pricing tiers: Custom Song ($49), Anime MV (+$80), Express (+$20), Global Release (+$39)
- Order page with a structured brief form
- PayPal checkout integration
- FAQ, terms and privacy sections
- Sample song and anime-style music video preview

## Stack

Static HTML, CSS and vanilla JavaScript. No framework. Served over HTTPS
through Cloudflare.
